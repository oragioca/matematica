📚 HOW TO PLAY

🎯 OBJECTIVE

Calculate the arithmetic mean of the data presented in different formats.

📝 HOW TO PLAY

  1. Observe the data in the chart or table
  2. Extract the numerical values
  3. Calculate the sum of all values
  4. Divide the sum by the number of values
  5. Round to the nearest whole number if needed
  6. Write the whole number
  7. Press SUBMIT or click the submit button

📊 QUESTION TYPES

  • Simple mean: Numbers in a table
  • Bar chart: Values as vertical bars
  • Data table: Organized information
  • Pie chart: Values as slices of a pie

🏆 BONUS SYSTEM

  • +5 bonus points every 3 consecutive correct answers
  • Extra life every 5 consecutive correct answers
  • Protective shield after 7 consecutive correct answers

🔄 PROGRESSION

  • Questions 3-5: Bar charts
  • Questions 6-9: Data tables
  • From 10th: All types including pie charts
